How to get started

Every section needs a heading and a paragraph or two. Long content, such as a very long web address, is wrapped gracefully thanks to the overflow-wrap rule applied to list items:

  • https://www.example.com/this/is/a/very/long/url/with/many/segments/and/characters/that/demonstrates/word/wrapping
  • Another list item, nicely spaced from its neighbours.
  • A third item to show the vertical rhythm.

The two-column zebra striping between sections happens automatically. Add or remove sections freely and the styling stays in sync.

An example image

Images float right on wider screens.

This image uses the img.right utility. On screens at least 480 px wide it floats to the right with a little padding, so the text wraps around it. On narrow screens it sits inline, above this paragraph.

  • Responsive by default.
  • No media queries required in your own markup.
  • Works with any image — just add class="right".

Things to remember

  • Use semantic elements: header, main, section, footer.
  • Avoid class names wherever an element will do.
  • Rebrand by overriding the --ogis-* tokens on :root.
  • British English throughout.

This page has no JavaScript and no build step of its own — the whole design comes from a single stylesheet.
